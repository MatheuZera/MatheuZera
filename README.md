## Sobre o Projeto

[![Captura de Tela do Produto][product-screenshot]](https://example.com)

Existem muitos templates de README disponíveis no GitHub, mas este foi adaptado para organizar e destacar seus projetos da melhor forma possível. O objetivo é que você não precise criar um README do zero toda vez que iniciar uma nova aplicação ou ferramenta.

Aqui estão os motivos:
* Seu tempo deve ser focado em criar algo incrível que resolva problemas.
* Tarefas repetitivas atrapalham o fluxo de desenvolvimento.
* Princípios DRY (Don't Repeat Yourself) devem ser aplicados em tudo! :smile:
